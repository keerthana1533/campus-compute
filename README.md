# CampusCompute

Command-line prototype for job scheduling and resource management (OS Level 3 Mini-Project).

## Prerequisites
Ubuntu / WSL Ubuntu with `gcc` and `make` (`sudo apt install build-essential`).

## Build
    make          # produces ./campuscompute
    make clean    # removes build/ and the executable

## Run
    ./campuscompute help
